# **App Name**: SalonFlow India

## Core Features:

- Salon Sign-up: Enable salons to sign up using phone OTP and provide initial details like salon name, language, and timezone.
- Service and Staff Management: Allow salons to add services with GST and pricing, and manage staff including schedules and commissions.
- Appointment Booking: Enable manual appointment booking and management, including walk-ins and appointment status updates.
- Daily Calendar View: Provide a calendar view (day/week) for managing appointments and staff schedules.
- GST Invoice Generation: Generate GST-compliant invoices and receipts for payments, with options for UPI and cash.
- WhatsApp Confirmation: Generate a tool using the WhatsApp Cloud API to send booking confirmations to customers using pre-approved templates.
- Subscription Billing: Manage subscription billing using Razorpay, including trial periods and paid plans with auto-renewal.

## Style Guidelines:

- Primary color: A vibrant indigo (#4B0082) to represent trust, professionalism, and modernity, aligning with the digital transformation of salon management.
- Background color: Light gray (#F0F0F0) provides a clean, neutral backdrop that enhances readability and reduces eye strain, crucial for long hours of salon management.
- Accent color: Soft lavender (#E6E6FA) offers a gentle contrast and adds a touch of elegance, complementing the primary color and creating a soothing visual experience.
- Body font: 'PT Sans' for body text, to offer a balance of modernity and warmth
- Headline font: 'Playfair' for headlines, for a fashionable, high-end feel.
- Use clear, minimalist icons representing salon services, appointment types, and payment methods for intuitive navigation.
- Design a calendar-first dashboard with one-click "New Appointment" functionality, ensuring ease of use on both mobile and tablet devices.
